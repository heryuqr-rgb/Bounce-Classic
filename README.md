# Bounce Classic

A small offline Android platform game inspired by classic feature-phone bounce games.

## Build
Run with JDK 17 and Android SDK Platform 35 installed:

```bash
gradle assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions builds the debug APK on every push to `main` and supports manual runs from the Actions tab.
